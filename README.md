# Wordezy Scramble

A daily word-unscramble game for [bgameworld.com](https://bgameworld.com), alongside Wordezy, Wordezy Search and When & Where.

Every day there are five scrambled words, one each of 4, 5, 6, 7 and 8 letters. Everyone gets the same five words (they're generated from the date, so nothing has to be fetched). Players tap or type the letters, shuffle the tiles, and race the clock. A hint locks the next letter in place and adds 10 seconds, so nobody gets stuck but hints can't buy a fast leaderboard time.

- **Daily**: free, one puzzle a day, timed. The clock starts when the player presses Play and survives a reload; a finished puzzle can't be replayed. Results share as a spoiler-free emoji grid.
- **Classic Unlimited**: endless five-word sets with free hints and a Skip button. Gated behind a one-time $2 unlock, which is a stub until payments are set up (same as Wordezy Search).
- **Leaderboard**: same Supabase project and account system as Wordezy and Wordezy Search. Guests can play; players with a name appear on the daily and all-time boards. Only a player's first finish each day counts.
- **Achievements, streaks, best time**: stored on the device.

## Run it locally

```bash
npm install
cp .env.example .env.local   # fill in the Supabase URL and anon key (same values as Wordezy Search)
npm run dev
```

## Database

The leaderboard needs the tables and functions in `supabase/migrations/20261008_wordezy_scramble.sql`. Run that file once in the Supabase SQL editor for the Wordezy project. It only creates new `wordezy_scramble_*` objects and doesn't touch the other games' tables.

Until it's run, the game still works: the leaderboard just stays hidden.

## Deploy (Cloudflare)

Same setup as Wordezy Search:

1. Push this repo to GitHub.
2. In Cloudflare, create a Worker from the repo. Build command `npm run build`, deploy command `npx wrangler deploy` (see `wrangler.jsonc`).
3. Add the `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` build variables.
4. Add the custom domain `wordezyscramble.bgameworld.com`.
5. In Google Search Console, add the subdomain and submit `https://wordezyscramble.bgameworld.com/sitemap.xml`.

## SEO

`index.html` carries the title and description, canonical URL, Open Graph and X/Twitter cards with `public/og-image.jpg`, `VideoGame` structured data, a `<noscript>` description, icons and a web manifest. `public/robots.txt` and `public/sitemap.xml` point at the subdomain.

## Word lists

`src/data/words.ts` is generated by `scripts/build_words.py`. Answers are common English words whose letters spell no other common word, so the intended answer is the obvious one; rarer real anagrams are accepted too. Proper names, profanity and grim words are filtered out.

Sources, cloned from GitHub into a download folder before running the script:

- [dolph/dictionary](https://github.com/dolph/dictionary): `enable1.txt` (ENABLE, public domain) and `popular.txt`
- [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords): `content/2018/en/en_50k.txt`, used only to rank words by everyday use

```bash
python3 scripts/build_words.py src/data/words.ts path/to/downloads
```

Changing the lists changes which words future days get, so avoid regenerating mid-day once the game is live.
